RBX Metro visual direction

Structure references: Microsoft Metro / Windows Phone principles — typography, clean open hierarchy, Pivot/Panorama-style navigation, responsive motion.
Graphic direction: late-2000s vector maximalism / Vectordelia motifs — cyan, magenta, lime, circles, dot grids, arrows, striped rings and flowing vector lines.

All decorative SVG artwork in this implementation is original and stored locally in rbx-metro-motif.svg. No third-party artwork is hotlinked or copied.
